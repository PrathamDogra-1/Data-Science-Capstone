# SpaceX Falcon 9 First Stage Landing Prediction

A Data Science and Machine Learning project that analyzes SpaceX Falcon 9 launches and predicts the success of first-stage rocket landings using Python.

## Project Overview

SpaceX uses reusable Falcon 9 rocket first stages to reduce the cost of space launches. Predicting whether the first stage will land successfully is an important part of understanding rocket reusability.

This project explores historical SpaceX launch data, performs exploratory data analysis (EDA), uses SQL for data analysis, visualizes launch-site information, and builds machine learning classification models to predict landing outcomes.

## Objectives

- Collect and explore historical SpaceX launch data.
- Perform data cleaning and preprocessing.
- Analyze launch and landing patterns.
- Visualize launch outcomes and launch-site locations.
- Apply SQL queries to explore the dataset.
- Build machine learning models to predict landing success.
- Evaluate and compare model performance.

## Dataset

The project uses historical SpaceX Falcon 9 launch data.

The notebook retrieves the dataset from publicly available historical CSV sources. The use of historical data helps avoid dependence on the live SpaceX API during normal notebook execution.

Example dataset source:

- [SpaceX Capstone Dataset](https://github.com/rampal-punia/IBM-DS-Capstone-Project-SpaceX)

The dataset includes information such as launch dates, flight numbers, launch sites, payloads, and landing outcomes.
